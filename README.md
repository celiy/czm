# czm

Celi's Zomboid Mods

Mods for the Project Zomboid (Build 42) collection.

## Install

```bash
./install.sh --list                 # available mods
./install.sh Gasoline_Degradation   # install (folder name or mod id)
./install.sh --dest <dir> <mod>     # custom mods folder (or set PZ_MODS_DIR)
./install.sh --workshop <mod>       # stage for Workshop upload in ~/Zomboid/Workshop/
```
